# Men's Hair To Stay, full site health check

**Date:** 25 September 2026
**Site:** menshairtostay.co.uk (live), repo `carlovacirca/mhts-site` at commit `92d38a5`
**Live bundle at time of check:** `assets/index-BC56om88.js`
**Nothing was changed, committed to the site, pushed or deployed.** This is a report only.

## What was checked, and how

| Area | Method |
|---|---|
| Raw HTML (pre-JavaScript) | `curl` on 7 live URLs, byte comparison |
| Rendered HTML (post-JavaScript) | Headless Chromium (Playwright) on **63 live URLs**, full DOM extract |
| Status codes and redirects | `curl -L` on 12 URL variants (http, www, trailing slash, bad URLs, pages.dev) |
| Sitemap and robots | Live fetch, parsed all 44 entries, compared against the repo file and the crawl |
| Structured data | Every `application/ld+json` block on all 63 pages, parsed and inspected |
| Internal linking | Full link graph from the 63 rendered pages, inbound counts, orphans, broken links |
| On-page SEO | Titles, metas, h1 counts, heading order, alt text, from the rendered DOM |
| Blog content | All 20 markdown files parsed with the `yaml` package, word counts, frontmatter |
| UX, UI, mobile | Screenshots at 390px and 1280px on 18 page types, plus measured overflow, tap targets, font sizes |
| Performance | `npx lighthouse@12` mobile on 4 live pages, plus `npm run build` output |
| Accessibility | Lighthouse accessibility category on the same 4 pages, plus heading order across 63 pages |
| Security | Live response headers, `npm audit`, secret scan of the working tree and all 700 commits |

Screenshots are in the session scratchpad at `shots/` (`<page>-390.png` and `<page>-1280.png`).
